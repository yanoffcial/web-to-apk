🛠️ Cara Build APK dari ZIP
1
Install Android Studio dari developer.android.com/studio
2
Extract ZIP → buka folder di Android Studio (File → Open)
3
Tunggu Gradle sync (~2-5 menit, perlu internet)
4
Build → Build Bundle(s) / APK(s) → Build APK(s)
5
APK di app/build/outputs/apk/debug/app-debug.apk 🎉
💡 Tidak mau install Android Studio? Pakai GitHub Actions — push ke GitHub, APK di-build otomatis gratis!
📖 Panduan Web2APK Studio
Apa yang dihasilkan?
ZIP file Android Studio project — Java source, XML layout, Manifest, Gradle, ikon semua ukuran. Build → APK siap install.

Preview website tidak muncul?
Normal! Beberapa website memblokir iframe (CORS/X-Frame-Options). Tapi APK asli menggunakan WebView native yang bisa membuka website apapun.
